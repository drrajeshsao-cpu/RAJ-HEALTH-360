# RAJ HEALTH 360 V7.0 Cloud Setup

1. Firebase Console: register a Web App.
2. Copy the Web App Firebase configuration JSON.
3. Authentication: enable Email/Password.
4. Create Cloud Firestore.
5. Create Cloud Storage.
6. Publish `firestore.rules`.
7. Publish `storage.rules`.
8. RAJ HEALTH 360 → Profile & Settings → Firebase Multi-Device Sync.
9. Paste Firebase configuration → Save & Initialize Cloud.
10. Sign in/create one account.
11. On the device with your current master data: Local → Cloud.
12. On the next device: use the same Firebase config and same account → Cloud → Device.
13. Keep Auto-sync + Realtime enabled after testing.
